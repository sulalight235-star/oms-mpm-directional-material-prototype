节点责任人 / 操作清单
① 发起人
业务人员（运营 / 销售助理）
在 MPM 列表页选择物料 → 填写或上传 Excel → 点击"执行"触发任务。预校验失败行直接返还，不送审。
③ 第一审核
陆雅静｜产业管理部门
审核奖励明细本身的合理性：奖励金额 / 比例是否在合理区间、奖励有效期是否符合业务节奏、说明文案是否规范。
④ 第二审核
汪李琼｜考核部门
审核奖励明细的合规性：是否触发考核口径变化、是否符合奖励办法、是否影响 KPI 结算。
⑤ 执行
MPM 系统自动
两节点全部通过后：明细入库 → 推送商城 / BI → 写操作历史（关联 flowId）→ 钉钉通知发起人成功。
哪些动作需要审核（动作清单）
动作 是否走审核 说明
批量新增（Excel 导入 / 列表批量）✅ 两级审核全部明细整体审核，任意行驳回 → 全单失败
批量修改（Excel 导入）✅ 两级审核同上
批量删除（Excel 导入 / 列表多选）✅ 两级审核同上
列表筛选 / 查询❌ 不需要不修改数据
导出当前查询 / 导出全部 / 我的导出任务下载❌ 不需要不修改数据
操作历史查询 / 历史导出❌ 不需要不修改数据
行内"重试同步"❌ 不需要只重发推送消息，不改业务数据
批量任务状态机
状态 触发 说明
PENDING_APPROVAL发起任务，预校验通过已送 H0，等待 / 流转中
APPROVINGH0 NODE_PASS 推进当前在某一审核节点，可在 H0 后台查看
REJECTED任意节点驳回明细不入库；钉钉通知发起人含驳回原因
TIMEOUT_REJECTEDH0 超时（默认 5 个工作日）同 REJECT；钉钉提示重新发起
EXECUTINGH0 FLOW_COMPLETEMPM 正在写库 + 推送商城/BI
EXECUTED入库成功钉钉通知发起人"已通过审核并执行成功"
EXECUTE_FAILED入库失败钉钉同时通知发起人 + 运维
H0_UNREACHABLEH0 多次重试无响应钉钉告警发起人 + 运维
