# 批量新增物料列表新增字段设计

## 背景

`MPM-物料-批量新增.html` 当前价格相关字段依次为“商城价、市场价”，需要在列表中新增“项目参考调拨价”和“描述”两个字段。

## 列顺序

新增后的局部列顺序固定为：

`商城价 → 市场价 → 项目参考调拨价 → 描述 → 物料品牌`

其他列顺序保持不变。

## 展示规则

- “项目参考调拨价”采用现有价格列的数字对齐样式，便于后续展示金额。
- “描述”采用现有文本省略样式，内容过长时单行省略，并通过 `title` 展示完整内容。
- 当前 4 条静态示例数据未提供对应业务值，两个新增字段均统一显示“—”。
- 空值使用现有 `.muted` 样式，保持与列表其他空字段一致。

## 布局规则

- 表格继续使用横向滚动，不压缩现有列。
- 表格最小宽度由 `1900px` 增加到 `2160px`，为两个新增字段预留空间。
- “项目参考调拨价”表头保持单行显示。
- 表头和每条数据行均新增两个单元格，列数必须完全一致。

## 验收标准

- 表头存在“项目参考调拨价”和“描述”。
- 两列严格位于“市场价”之后、“物料品牌”之前。
- 4 条数据行均补齐两个空值单元格。
- 每行单元格数量与表头数量一致。
- 横向滚动正常，新增列不会遮挡或挤压相邻字段。
