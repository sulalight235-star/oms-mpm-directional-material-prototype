# “推荐”字段下拉多选设计

## 背景

`MPM-物料-待我审核-新增物料审核详情.html` 中“推荐”字段当前使用原生 `select multiple`，页面呈现为固定高度的列表框，与同区域其他输入型控件的视觉和操作方式不一致。

## 方案

将“推荐”字段替换为自定义下拉多选框：

- 默认状态与普通输入框一致，未选择时显示“请选择”。
- 点击输入区域展开选项面板，包含“核心主推、主推、常规、零星”。
- 每个选项使用复选框表达多选状态，可任意组合选择。
- 已选值以标签形式展示在输入区域，标签支持通过关闭按钮取消选择。
- 点击控件外部或按 `Escape` 关闭下拉面板。
- 保留键盘聚焦、`aria-expanded`、`aria-controls` 等基础可访问属性。

## 视觉规则

- 控件默认高度为 30px，与现有 `.f-input`、`.f-select` 保持一致。
- 多个标签超出单行时允许控件自然增高，不截断已选内容。
- 展开状态使用现有主色边框和浅色聚焦阴影。
- 下拉面板位于控件下方，使用白色背景、现有圆角及阴影变量。

## 交互规则

1. 点击输入区域切换展开/收起状态。
2. 点击选项仅改变对应选中状态，不立即关闭面板。
3. 点击标签关闭按钮取消对应选项，且不触发展开状态切换。
4. 点击页面其他区域关闭面板。
5. 再次打开时保留当前选择结果。

## 验收标准

- 四个推荐项均可独立选择和取消，可同时选择多项。
- 输入区域准确显示全部已选标签；无选择时显示“请选择”。
- 下拉面板、复选框和标签状态始终同步。
- 点击控件外部及按 `Escape` 可正常收起。
- 不影响同一行“行业、厂控物料、动销”字段及页面其他现有交互。
