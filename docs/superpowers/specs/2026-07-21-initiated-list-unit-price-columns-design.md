# “我发起的”列表新增单位与价格字段设计

## 背景

`MPM-物料-我发起的.html` 包含“新增审核、修改审核、MDM增量审核、定向物料新增审核”4 个子 Tab。所有子 Tab 共用同一套表头和 `renderTable()` 渲染函数，前三个 Tab 使用 `ROWS_NEW`，定向物料新增审核使用 `ROWS_DIRECTIONAL`。

## 新增字段与顺序

在“规格”字段之后依次新增：

`单位 → 市场价 → 商城价 → 项目参考调拨价`

新增后的局部列顺序为：

`型号 → 规格 → 单位 → 市场价 → 商城价 → 项目参考调拨价 → 品牌`

## 数据规则

- 为 `ROWS_NEW` 和 `ROWS_DIRECTIONAL` 中的示例物料补充 `unit`、`marketPrice`、`mallPrice`、`projectTransferPrice` 属性。
- 单位根据物料类型配置为“个、台、块、套、只、根”等合理虚拟值。
- 三类价格统一展示两位小数。
- 虚拟价格通常遵循：市场价不低于商城价，商城价不低于或接近项目参考调拨价。
- 待审核、资料待补充等特殊示例允许项目参考调拨价显示“—”，模拟尚未形成参考价格的业务状态。
- 渲染时使用空值兜底，缺失字段统一显示“—”，不得出现 `undefined` 或 `null`。

## 展示规则

- “单位”使用普通文本样式。
- 三个价格字段使用统一的价格样式和等宽数字特性，便于横向比较。
- 空价格使用弱化文本样式。
- 表头和所有数据行必须同时增加 4 个单元格。
- 表格最小宽度从 `2400px` 增加到约 `2880px`，继续使用现有横向滚动。

## Tab 一致性

- 4 个子 Tab 使用完全一致的列结构和列顺序。
- 切换任意 Tab 后，新增字段必须正常显示。
- 切换 Tab 不得影响勾选、批量撤回、分页及状态标签等现有交互。

## 验收标准

- 表头在“规格”之后依次显示“单位、市场价、商城价、项目参考调拨价”。
- 4 个子 Tab 均展示新增字段。
- 所有示例行的表头数量与单元格数量一致。
- 价格统一为两位小数或“—”，页面不存在 `undefined`。
- 表格横向滚动正常，新增字段不会挤压或遮挡相邻列。
