# 我发起的—删除导入批次按钮设计

## 目标

从“我发起的”页面操作栏中移除不再需要的“导入批次”入口。

## 调整内容

- 删除“导入批次”按钮。
- 同步移除按钮内“正在导入批次...”消息反馈入口。
- 删除后“导入批改”与“提交”按钮自然相邻。

## 实现约束

- 不修改“刷新、批量撤回、批量导出、导入批改、提交、放弃”的样式、顺序和点击逻辑。
- 不修改导入批改弹窗、批量导出下拉菜单及列表内容。
- 不增加替代入口或空白元素。

## 验收标准

1. 页面操作栏不再显示“导入批次”。
2. 页面源码不再包含“正在导入批次...”文案。
3. “导入批改”后紧邻“提交”。
4. 其他操作按钮及相关交互保持正常。
