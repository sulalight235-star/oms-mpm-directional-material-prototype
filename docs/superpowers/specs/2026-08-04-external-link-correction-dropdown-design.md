# 批量新增物料列表—外链批改下拉设计

## 目标

在“批量新增物料列表”操作栏中，为外链批改提供独立入口，并保持与现有“关联”下拉菜单一致的视觉及交互体验。

## 页面调整

- 在“错误批改”左侧新增文字按钮“外链批改”。
- 按钮显示下拉箭头，点击后在按钮下方展开菜单。
- 下拉菜单包含“下载模版”和“批改外链”两个文字操作项。

## 交互规则

- 点击“外链批改”切换下拉菜单的展开和收起状态。
- 点击页面其他区域时收起下拉菜单。
- 打开“外链批改”菜单时关闭“关联”菜单；打开“关联”菜单时关闭“外链批改”菜单。
- 点击菜单项后收起菜单，并通过页面现有消息提示组件反馈操作结果。
- 当前未提供真实模板文件及外链地址，因此本次仅实现原型交互反馈，不执行真实下载或页面跳转。

## 实现约束

- 复用现有 `.list-op-wrap`、`.list-op.dropdown`、`.dropdown-menu` 和 `.dropdown-item` 样式。
- 不调整其他操作按钮的顺序、样式和业务逻辑。
- 修改范围仅限 `MPM-物料-批量新增.html` 及本设计说明。

## 验收标准

1. “外链批改”位于“错误批改”左侧。
2. 点击后展示“下载模版”和“批改外链”。
3. 两个下拉菜单不会同时展开。
4. 点击菜单外区域或菜单项后，下拉菜单正确收起。
5. 页面原有“关联”下拉及其他按钮交互不受影响。
