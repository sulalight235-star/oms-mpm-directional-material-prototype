# 我发起的—导入批改弹窗设计

## 目标

在“我发起的”页面增加导入批改入口，为撤回或驳回状态的物料及外链数据提供模板下载、文件选择和执行操作的原型展示。

## 入口设计

- 在操作栏右侧“批量导出”按钮后新增文字按钮“导入批改”。
- 点击“导入批改”后打开同页弹窗。

## 弹窗设计

- 弹窗标题为“导入批改”。
- 参考“物料列表”页面的导入批改弹窗，使用“修改项、模板下载、操作”三列表格布局。
- 第一行修改项为“批改物料（撤回/驳回）”，后方提供“下载、选择文件、执行”文字按钮。
- 第二行修改项为“批改外链（撤回/驳回）”，后方提供“下载、选择文件、执行”文字按钮。
- 弹窗右上角提供关闭按钮，点击遮罩区域也可关闭弹窗。

## 原型反馈

- 点击“下载”展示对应模板已下载的成功提示。
- 点击“选择文件”展示对应批改文件已选择的成功提示。
- 点击“执行”展示已加入异步任务的成功提示。
- 本次不执行真实文件下载、文件上传或后台任务，仅实现页面原型交互。

## 实现约束

- 复用“我发起的”页面现有遮罩、消息提示、按钮变量及视觉风格。
- 新增弹窗专用表格样式，不影响原撤回确认弹窗。
- 不修改列表数据、筛选条件及其他操作按钮逻辑。

## 验收标准

1. “导入批改”位于操作栏右侧“批量导出”之后。
2. 点击按钮可打开包含两种批改模板的弹窗。
3. 两行均包含“下载、选择文件、执行”三个文字操作。
4. 所有文字操作均能展示对应反馈。
5. 关闭按钮和遮罩点击均可关闭弹窗。
6. 原撤回确认弹窗及页面其他交互不受影响。
