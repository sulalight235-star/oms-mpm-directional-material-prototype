# 我发起的—操作栏文字按钮设计

## 目标

统一“我发起的”页面主要操作入口的视觉样式，将指定操作改为蓝色文字按钮，并将“废弃”文案调整为“放弃”。

## 调整范围

- “刷新”改为蓝色文字按钮。
- “批量撤回”改为蓝色文字按钮。
- “批量导出”改为蓝色文字按钮，保留下拉箭头及原有下拉菜单。
- “导入批改”改为蓝色文字按钮，保留弹窗交互。
- “提交”改为蓝色文字按钮。
- “废弃”改名为“放弃”，并改为蓝色文字按钮。
- “导入批次”继续保留当前带边框按钮样式。

## 视觉规则

- 文字按钮不显示边框和背景色。
- 默认文字颜色使用页面主色蓝 `var(--primary)`。
- 鼠标悬停时切换为 `var(--primary-hover)` 并显示下划线。
- 保留原按钮高度和点击区域，避免操作栏发生明显跳动。

## 交互规则

- 不修改刷新、批量撤回、批量导出、导入批改、提交的原有点击逻辑。
- “放弃”继续沿用原“废弃”操作反馈，但反馈文案同步调整为“已放弃所选物料”。
- “批量导出”的展开、收起及菜单项操作保持不变。

## 验收标准

1. 指定六个操作均显示为蓝色文字按钮。
2. “导入批次”仍显示为带边框按钮。
3. 页面不再显示“废弃”按钮，显示“放弃”按钮。
4. 点击“放弃”后提示“已放弃所选物料”。
5. 批量导出下拉和导入批改弹窗交互不受影响。
