# 物料列表页设计说明

## 目标
为 OMS-MPM 定向物料原型补充一个新的“物料列表”页面，并把入口同时接到首页 `index.html` 与工作台 `oms-mpm-物料工作台原型.html`。页面沿用当前原型的 AntD 风格，同时参考旧系统截图的信息架构，实现“进入物料列表”与“从列表进入详情页”的主链路。

## 设计边界
- 做纯静态 HTML 原型，不接真实后端。
- 交互深度采用“高保真关键交互”：
  - 左侧类目树展开/收起与选中高亮；
  - 顶部筛选区查询与重置；
  - 工具栏导出下拉展开；
  - 表格分页切换；
  - 点击物料编码或名称跳转现有 `物料审核详情.html`。
- 不实现真实数据筛选、真实导出、真实上下架接口。

## 入口设计
1. `index.html`
   - 在首页原型入口列表中新增“物料列表”入口。
   - 入口文案突出“商城物料主数据列表浏览与筛选”。
2. `oms-mpm-物料工作台原型.html`
   - 保持“物料列表”为默认选中功能。
   - 点击功能项或底部“进入”按钮时跳到新的 `物料列表.html`。

## 页面结构
新建 `物料列表.html`，整体沿用现有原型的顶部导航 + 页签样式，主体采用“筛选区 + 左树右表”布局：

1. 顶部筛选区
   - 两行筛选字段，参考截图保留主要检索习惯：物料编码、物料名称、型号、描述、品牌、货主。
   - 右侧放“查询”“重置”按钮。
   - 查询仅做前端提示与标题更新；重置恢复默认值。

2. 左侧类目树
   - 展示一级类目与部分二级类目。
   - 支持展开/收起。
   - 选中后刷新右侧当前分类标题与结果提示。
   - 默认选中“全部”，并提供与截图接近的“电动工具”示例节点。

3. 右侧列表区
   - 顶部操作条：显示“操作 / 数据范围 / 刷新”等文字操作，以及“提交外重复校”“物料清洗”“导入批改”“推送”等工具按钮。
   - 删除工具按钮旁的“动力工具”字样。
   - 导出按钮采用下拉菜单，点击后直接展开多个导出项，不增加额外引导提示。
   - 中间使用数据表格，字段以截图为参考，保留货主、类目、品牌、型号、编码、名称、描述、基本单位、供应商、规格、项目报价员、产品经理、订单执行员、市场价、商城价、上下架、可售等列。
   - “编码”“名称”使用链接样式，点击跳转到 `物料审核详情.html`。

5. 导出弹窗链路
   - 点击“全部导出”时，先展示确认弹窗：`共计导出85641条数据，是否继续导出？`，并展示提示文案 `注意：导出物料越多，导出时间越长。`。
   - 点击“自定义导出”时，展示字段选择弹窗，界面结构参考用户提供截图：导出方式单选、是否保存为模板、字段搜索框、左右字段列表、底部“取消 / 提交”按钮。
   - 点击“商城价导出”“外链导出”时，为保持一致性，沿用“全部导出”的确认弹窗链路。
   - 任一导出链路在用户确认继续或提交后，都继续弹出审批提示：`部门经理以下提交导出进行流程审批，详情请查看流程编码XXXXXXXXX1`。
   - 审批提示确认后，前端静态原型模拟“流程通过 → 自动触发系统任务执行 → 提示你有一条新任务执行成功”的串联反馈。

4. 分页区
   - 页面底部提供总条数、页码、每页条数、跳页输入等静态原型交互。
   - 支持点击页码切换当前页高亮。

## 视觉规则
- 继承现有页面的颜色 token、边框、阴影、按钮与页签风格，避免做成旧系统高仿版。
- 参考截图保留高信息密度与“左树右表”的业务感，但使用更整洁的间距与可读性。
- 不使用 emoji 作为结构性图标；优先复用现有 SVG/纯文本按钮样式。

## 交互规则
- 点击首页/工作台入口：进入 `物料列表.html`。
- 删除筛选区右上角的补充说明文案，保留更简洁的筛选头部。
- 点击类目树节点：高亮当前项，更新右侧标题与提示文案。
- 点击“查询”：显示消息提示，列表标题中反映当前检索关键词。
- 点击“重置”：恢复筛选项默认值与“全部”分类。
- 点击“导出”：直接展开/收起下拉菜单。
- 点击“全部导出”“商城价导出”“外链导出”：先弹确认框，再弹审批提示，再模拟任务执行成功提示。
- 点击“自定义导出”：先弹字段选择弹窗，提交后再弹审批提示，最后模拟任务执行成功提示。
- 点击分页：切换当前页显示状态。
- 点击编码/名称：跳转详情页。

## 验收标准
- `index.html` 可进入新物料列表页。
- `oms-mpm-物料工作台原型.html` 中物料列表可进入新页面。
- 新页面具备筛选区、类目树、操作条、表格、分页、导出下拉。
- 筛选区副文案与工具栏“动力工具”字样已删除。
- “全部导出”可弹出确认框，并继续进入审批提示与任务成功提示。
- “自定义导出”可弹出字段选择框，并继续进入审批提示与任务成功提示。
- 编码或名称可跳到现有详情页。
- 视觉风格与当前原型体系一致，不突兀。
