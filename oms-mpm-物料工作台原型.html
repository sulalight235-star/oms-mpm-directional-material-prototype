💡 MPM v4.8.0 操作提示 收起 ▾
功能入口：
1. MPM → 工作台 → 类目管理 → 四级类目列表 → 行操作 「资质配置」
2. MPM → 工作台 → 类目管理 → 四级类目列表 → 顶部 「导出」 下拉 → 导出资质配置
3. MPM → 类目管理 → 资质配置-编辑页 → 货主块 「查看j记录」
4. MPM → 工作台 → 类目管理 → 四级类目列表 → 顶部 「导入批改」 按钮 → 弹窗内新增 「批量维护资质规则」 行 → 下载/上传模板
5. MPM → 工作台 → 物料管理 → 「新增物料」 物料详情页 / 编辑页底部新增 "资质资料" 卡片区
6. MPM → 工作台 → 物料管理 → 「批量新增物料」
7. MPM → 工作台 → 物料管理 → 物料列表 → 导入批改 → 顶部 「批增批改资质文件」 按钮
8. MPM → 物料管理 → 物料列表 → 选中物料(多选/筛选) → 自定义导出勾选 「导出资质资料」 字段
9. SCP新增/修改入口；PLM新增/修改入口；OMS新增/修改入口；IQS新增入口；增加限制条件
10. SCP物料详情界面组件样式更新：SCP → 物料管理 → 项目物料提报管理 / 我的物料 / 待提交物料 / 我的申请 → 物料详情界面
11. MPM物料详情界面组件样式更新：MPM → 物料对接 → 待推送物料列表 → 物料详情界面；MPM → 物料对接 → 对接物料列表 → 对接物料详情界面
12. 既有审核单详情页底部新增 "AI 资质审核建议" 卡片区块
13. MPM → 工作台 → 类目管理 → 四级类目列表 → 编辑类目 → 前台提示文案（MPM 新增物料 / MPM 修改物料 / SCP 新增物料 / SCP 修改物料 → 属性维护模块）
14. ossbrowser / OSS 客户端 → MPM OSS 指定 Bucket → 指定目录前缀。
本期内容：
1. 资质规则配置不需要审批——任何新增/修改/启停/删除均即时生效，不影响已审核通过物料。
2. (类目+货主) 业务键全局唯一——一个四级类目下一个货主只能配一条未删除的资质规则。
3. (物料编码+OSS地址) 业务键全局唯一——同一物料下同一 OSS 文件地址不重复关联。同一物料同一资料附件类型允许关联多个文件。
4. 资质规则按新增物料场景生效——本期规则用于新增物料场景校验；修改物料强制附件拦截不纳入本期。
5. 属性设置本期不开发——属性条件表达式、属性项/属性值引用保护等能力不纳入本期。
6. 类目前台提示文案仅提示不拦截——提示文案只用于 SCP、MPM 新增/修改物料属性维护模块展示，不参与资质规则命中、属性校验、提交拦截或 AI 审核判断；类目提示文案新增/修改不写入资质操作历史。
8. OSS URL 域名约束——所有进入 MPM 的 OSS URL 必须以 https://mpm-oss.xianheng.cn/ 开头，否则返回 INVALID_OSS_URL 错误码。
9. AI 审核为建议方，非决策方——审核员可参考可忽略，最终决策不受 AI 强制约束；不一致时弹窗提示但不强制说明。
10. 驳回必填理由——审核员驳回时驳回理由必填(≥10 字符)；不依赖驳回理由通过 AI 一致性比对。
11. 已审核通过的历史物料不受规则变更或 AI 升级反向影响——规则修改 / AI 模型升级只对下一次新审核生效；不批量重审历史。
12. 批量新增列表永久保留——仅"草稿"状态可手工删除(逻辑删除)；"提交中" / "已提交"状态不可删。
13. 数据权限——批量新增列表本人只看自己，管理员看全部；资质规则配置、OSS 客户端资质上传目录权限仅商品审批经理可维护/使用，他人只读或无 OSS 上传权限。
💡 MPM v4.7.0 操作提示 收起 ▾
演示操作：
1. 点击 「物料列表」，查看物料编码，进入物料详情，查看物料字段变更信息
2. 进入 「咸亨产品奖励管理」，体验奖励配置列表、批量导入、操作历史
本期改动：
• 新增 咸亨产品奖励管理 模块：Excel 批量导入维护奖励配置（增/改/删）+ H0 两级审核 + 异步任务执行，审核通过后同步推送商城库
• 新增 导出：无需审核权限，一键导出全部奖励配置（归档 / 对账 / 下游核对）
• 新增 操作历史：记录每次配置变更，支持导出追溯修订内容
• 新增 接口字段：商城前台展示物料奖励标签及金额 / 比例 / 说明文案
• 角色权限：新增 【采购员（新运营）】；系统管理员、审批经理增加采购员及咸亨产品激励模块权限
