💡 MPM v4.8.0 操作提示 收起 ▾
演示操作：
a) 类目管理 → 四级类目列表 → 行操作 「资质配置」
b) 类目管理 → 四级类目列表 → 顶部 「导入批改」 → 弹窗内新增 「批量维护资质规则」 行 → 下载/上传模板
c) 物料管理 → 新增物料 / 批量新增 / 我发起的 / 待我审核 / 待我审核（生产）/ 我暂存的 → 资质资料区块 「+ 上传文件」 按钮
d) 物料管理 → 批量新增 → 批量新增列表第二步 "关联资质文件" 前的资料准备
e) 物料管理 → 文件管理 → 批增上传资质文件 入口
f) 物料管理 → 物料列表 → 导入批改 → 删除【关联产品资料、关联检测报告、关联质量证明】
g) 物料管理 → 物料列表 → 导入批改 → 新增【新增\批改物料附件】
本期改动：
1. MPM 内资质要求规则配置模块（单类目「资质配置」按钮 +「批量维护资质规则」Excel 模板入口）
2. MPM 内置文件上传组件 + 对外文件上传 REST API（本期 OSS 唯一守门员）
3. 7 个物料创建/修改入口的统一资质校验
4. AI 资质审核引擎（异步 OCR + LLM）+ 既有审核单 AI 建议回写 + 决策弹窗（不一致提示 / 驳回理由 / 通过确认）
5. 批增批改资质文件独立入口（Excel 三列：物料编码 / 资质类型 / OSS URL）
6. 物料资质文件 URL 列表 Excel 异步导出（4 列：物料编码 / 文件类型 / 文件名称 / 文件 URL 地址）
7. 物料详情的操作历史记录与查询
8. 类目资质规则操作历史记录与查询
💡 MPM v4.7.0 操作提示 收起 ▾
演示操作：
1. 点击 「物料列表」，查看物料编码，进入物料详情，查看物料字段变更信息
2. 进入 「咸亨产品奖励管理」，体验奖励配置列表、批量导入、操作历史
本期改动：
• 新增 咸亨产品奖励管理 模块：Excel 批量导入维护奖励配置（增/改/删）+ H0 两级审核 + 异步任务执行，审核通过后同步推送商城库
• 新增 导出：无需审核权限，一键导出全部奖励配置（归档 / 对账 / 下游核对）
• 新增 操作历史：记录每次配置变更，支持导出追溯修订内容

• 角色权限：新增 【采购员（新运营）】；系统管理员、审批经理增加采购员及咸亨产品激励模块权限
