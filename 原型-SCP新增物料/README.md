# SCP 新增物料原型（批量 + 单个 + 详情入口）

咸亨国际供应商协同平台（SCP）「物料管理」下新增物料、批量新增、我的物料、我的申请、项目物料提报管理、提报记录详情等界面的高保真可点原型。HTML 页面可双击在浏览器打开。

新增列表/详情页共用 `scp-common.css` 外壳（顶部条 + 左侧导航 + Tab 栏），`SCP-项目物料提报管理.html` 中「查看详情」可跳转到 `SCP-提报记录详情.html`。

左侧菜单已实现对应跳转：
- 我的物料 → `SCP-我的物料.html`
- 我的申请 → `SCP-我的申请.html`
- 项目物料提报管理 → `SCP-项目物料提报管理.html`
- 待提交物料 → `SCP-待提交物料.html`
- 新增物料 → `SCP-单个新增物料.html`
- 批量新增 → `SCP-批量新增物料.html`

详情页交互：
- `SCP-我的物料.html` 中点击物料编码或名称进入 `SCP-我的物料-物料详情.html`
- `SCP-待提交物料.html` 中点击物料编码或名称进入 `SCP-待提交物料-物料详情.html`

## 已实现的交互（纯前端，无后端）

**单个新增物料**
- 物料类型单选、含安装费/含检测费/含运费/已停产/倍数下单/详询客服 等勾选与单选联动
- 类目、关联项目选择（原型用输入模拟）、类目 ✕ 清除
- 「智能赋码」一键带出税收分类编码/名称/简称/税率
- **资质资料**（对齐 MPM 4.8.0 资质类型）：CCC 试验报告 / 质检报告 / 检验检疫 / LA / 其他自愿性认证，逐类「上传文件」后回显文件名，可删除
- 外部链接/价格佐证「+点击添加」动态增删行
- 图文信息 主图/详情图「上传」回显占位缩略图，可删除
- 顶部/底部「保存 / 提交 / 关闭」：提交时校验必填项（品牌/名称/型号/基本单位/类目/毛重/市场价/起订量/税收名称/简称/税率），缺失项红框 + 轻提示并滚动定位；通过后提示"已提交审核"
- 拓展属性蓝色标题 hover 显示要求该属性的平台项目

**批量新增物料**
- 操作流程 3 步说明（前往维护 / 查看导入规范 链接）
- 关联项目下拉、模板与参考信息下载链接（模拟下载提示）
- 上传图片（多选，回显"已选 N 张"）、导入物料（选 .xlsx，回显文件名可删）
- 「开始导入」校验关联项目 + 导入文件必填，通过后提示"导入任务已创建"

## 与 PRD 的对应

「资质资料」区块对应 PRD《MPM v4.8.0 商品资质资料管理》§3.2.7 SCP 新增/修改物料接口扩展 + §3.2.1 资质类型枚举；SCP 侧界面上传资质文件后随物料接口带 `qualFiles[]` 入参，本原型还原了这一上传入口。
