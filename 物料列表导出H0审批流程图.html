发起人 H0 / 部门经理 追加审核 MPM / 通过 失败 / 异常
流程节点说明
导出发起人
物料列表用户
发起筛选导出、外链价格导出、商城价导出、自定义导出或全部导出。发起后仅创建任务，不立即生成文件。
MPM 任务中心
导出任务承载方
保存任务类型、发起人、发起时间、导出范围、预计导出数量，并将任务置为“待 H0 审批”。
部门经理审核
发起人部门经理
所有导出均必须审核。即使发起人属于万聚商品部门或万聚商城部门，也不得跳过部门经理节点。
张银群追加审核
万聚商品部门
部门经理不属于万聚商品部门或万聚商城部门时追加。通过后才允许 MPM 执行导出任务。
驳回处理
任一审批节点
H0 通知任务发起人；MPM 将导出任务标记为执行失败，并记录驳回人、时间、原因。
导出执行
审批通过后触发
审批通过前不执行导出；通过后按既有任务中心逻辑进入待执行、执行中、执行完成或执行失败。
审计日志
全链路追溯
记录发起人、部门、任务类型、审批人、是否追加张银群、审核意见、最终任务状态。
异常补偿
H0 回调异常
审批异常或回调失败时记录异常日志，任务状态进入执行失败或待重试，具体补偿策略由研发方案确认。
哪些导出需要 H0 审批
导出动作 是否审批 说明
筛选条件导出需要 H0 审批按当前查询条件导出物料数据，审批通过前不生成文件。
外链价格导出需要 H0 审批任务类型在 H0 审批页展示为外链价格导出。
商城价导出需要 H0 审批任务类型在 H0 审批页展示为商城价导出。
自定义导出需要 H0 审批需展示自定义导出范围和预计导出数据量。
全部导出需要 H0 审批数据范围最大，审批链路与其他导出一致。
H0 审批页展示字段
字段 字段名称 必填 展示说明
taskType任务类型Y外链价格导出、商城价导出、自定义导出、全部导出等。
applyUserName发起人Y导出任务发起人姓名。
applyUserNo发起人工号Y用于审批、通知、日志追溯。
applyDeptName发起部门Y展示发起人所属部门，用于审核人判断。
applyTime发起时间Y导出任务发起时间。
exportScope导出范围N筛选导出、勾选导出、全部导出等。
exportCount导出数据量N本次预计导出的物料数量。
任务状态机
场景 H0 审批状态 系统任务状态 后续动作
任务创建并发起 H0 审批中 待 H0 审批 暂不执行导出。
部门经理通过，且属于万聚商品部门/万聚商城部门 审批通过 待执行 / 执行中 不追加审核，执行导出任务。
部门经理通过，但不属于万聚商品部门/万聚商城部门 追加审批中 待追加审核 流转至万聚商品部门-张银群。
张银群审核通过 审批通过 待执行 / 执行中 执行导出任务。
任一审批节点驳回 审批驳回 执行失败 H0 通知任务发起人，MPM 不执行导出。
H0 审批异常或回调失败 审批异常 执行失败 / 待重试 记录异常日志，补偿策略由研发方案确认。
