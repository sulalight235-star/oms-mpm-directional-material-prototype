# MPM 物料主数据系统原型集合

## 项目说明

本仓库集中维护 MPM 物料主数据及相关业务系统的静态交互原型，用于内部需求讨论、产品评审和交互确认。

原型预览门户覆盖以下板块：

- MPM：物料创建、审核、资质配置、物料对接、任务中心、文件管理及系统管理等；
- OMS：订单管理及跨系统定向物料场景；
- SCP：供应商物料新增、申请和项目物料提报；
- CRM：客户及项目工作台；
- 咸亨商城：商品详情与产品奖励展示；
- 相关需求、交互说明和流程图。

## 快速入口

打开根目录的 `index.html`，即可通过统一门户进入各业务原型。

主要目录及文件：

- `MPM-*.html`：MPM 各业务模块原型；
- `OMS-*.html`：OMS 相关原型；
- `CRM-*.html`：CRM 相关原型；
- `原型-SCP新增物料/`：SCP 物料管理与项目物料提报原型；
- `云端截图-*.html`：跨系统页面还原与对照原型；
- `docs/`：设计说明、规格和实施计划；
- `*.md`：需求、交互及业务说明文档。

## 本地运行

本项目为纯静态 HTML 原型，无需安装依赖。

### 方式一：直接打开

使用浏览器打开根目录的 `index.html`。

### 方式二：使用本地静态服务

如果你希望通过本地服务预览，可在仓库目录执行任一方式：

```bash
python3 -m http.server 8000
```

然后在浏览器访问：

```text
http://localhost:8000/
```

## 使用边界

- 本仓库仅供公司内部产品设计、业务讨论和评审使用；
- 页面均为静态交互原型，不连接真实后端，不执行真实上传或数据持久化；
- 页面中的业务数据均为原型演示内容，不应写入真实账号、凭据或生产数据；
- `参考图/`、本地截图、浏览器调试配置和运行日志不纳入版本管理；
- 页面之间包含基础跳转关系，可通过预览门户联动查看。
